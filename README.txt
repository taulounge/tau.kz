TAU Lounge Restaurant — упрощённый статический сайт для GitHub Pages.

Загрузка: распакуйте архив и загрузите ВСЁ содержимое папки TAU-Lounge в корень репозитория. В Settings → Pages выберите Deploy from a branch → main → /(root).

Страницы: index.html (главная и меню), order.html (корзина и оформление).
Фотографии блюд извлечены из предоставленного PDF-меню TAU. Название, описание и цена показываются под фотографией.
